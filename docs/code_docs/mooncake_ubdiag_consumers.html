Mooncake UbDiag Code Walkthrough

Mooncake 消费侧：统一链接 UbDiag::ubdiag_lib

覆盖源文件：mooncake-store/src/CMakeLists.txt、mooncake-transfer-engine/src/CMakeLists.txt、mooncake-integration/CMakeLists.txt

阅读重点：三层分发对 Mooncake 业务模块保持无感。每个模块只 include `FindUbDiag.cmake`，然后链接统一 target `UbDiag::ubdiag_lib`；具体命中 L1/L2/L3 由 FindUbDiag.cmake 负责。

三层分发消费入口 本次 CLI 集成复用同一解析结果
模块行号作用
mooncake-storeL250-L252Store 打点链接统一 UbDiag target。
transfer-engineL2、L50-L64Transfer Engine 打点链接统一 UbDiag target。
mooncake-integrationL104-L106Python store binding 链接统一 UbDiag target。
