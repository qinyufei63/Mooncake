Mooncake UbDiag Code Walkthrough

build_rpm.sh：UbDiag CLI/lib/config 打进 Mooncake RPM

源文件：scripts/build_rpm.sh

阅读重点：RPM 打包脚本不再猜测 UbDiag 产物，而是读取 CMake 生成的 `mooncake_ubdiag_rpm.env`。L1 拷贝 vendored build output，L2 拷贝客户系统 UbDiag，L3 跳过 runtime。
